Theory, formulas, and interactive analysis of the 64-bit Hamming Code

HAMMING CODE FORMULA
2r ≥ m + r + 1
m=Number of data bits64
r=Number of parity bits?
n=Total codeword lengthm+r
1Try r=6:  26=64  vs  64+6+1=71  →  64<71 ✗
2Try r=7:  27=128  vs  64+7+1=72  →  128≥72 ✓
∴r = 7 parity bits  →  n = 64+7 = 71 bits

ADVANCED HAMMING MATRIX REPRESENTATION
Mathematical matrix formulation. For advanced study only.
Parity-Check Matrix (H)

The H matrix is 7×71 where column j is the 7-bit binary representation of j. The syndrome is:

S = H · rT

If S = 0, no error. If S ≠ 0, S as decimal gives the error position.

Generator Matrix (G)

The G matrix encodes data vector d into codeword c:

c = d · G

G is 64×71. Each row places a data bit and marks which parity bits it influences.

⚠ The full H matrix (7×71) is large. Use horizontal scrolling to view.

ABOUT THIS PROJECT
64-bit Hamming Code Interactive Laboratory

        

        

          
PROJECT OVERVIEW
A professional interactive educational simulator for the 64-bit Hamming Code, designed for Computer Organization & Architecture and Computer Networks coursework.
Implements the complete SEC (Single-Error Correction) workflow: encode 64 data bits into a 71-bit Hamming codeword, inject controlled single-bit errors, perform syndrome-based detection, and correct to recover original data.
⚠ This simulator demonstrates Single-Error Correction (SEC) only. It does not correct multiple simultaneous bit errors.
